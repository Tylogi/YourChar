# YourChar native-style UI concept assets

Preview: [ui-apple-inspired.html](../ui-apple-inspired.html).

Reference pages: [Apple Music](https://www.apple.com/apple-music/) and [Apple Human Interface Guidelines: Materials](https://developer.apple.com/design/human-interface-guidelines/materials).

`coast.png` is original AI-generated artwork created with the built-in imagegen tool. It supplies the photographic cover, a role card, and the blurred conversation background. Other covers and icons are rendered locally in CSS and SVG. No Apple artwork or logos are included.

Final image-generation prompt:

> Use case: photorealistic-natural. Asset type: premium full-bleed editorial album cover for a sophisticated AI companion application, no UI. Primary request: A quiet coastal road at dusk, the ocean to the left and steep forest-covered headland to the right, a single tiny distant human silhouette near the ocean edge for scale, viewed from a slightly elevated position. Cinematic analog medium-format photography, extraordinary natural detail, ethereal fog around the hills, rich desaturated sage green, blue-grey sea, warm peach twilight horizon, subtle film grain. Composition: landscape 3:2, rolling headland and pines concentrated on the right third, plenty of atmospheric open sky and water in the left half to overlay title text later. Mood: intimate, contemplative, contemporary art-directed music editorial. Avoid: text, typography, logos, watermarks, UI, illustration, vector shapes, neon colors, excessive glow. This is the final bitmap hero asset for a local HTML prototype.

The UI is an independent interactive concept, with simulated characters and messages. Favorites and appearance are persisted to local storage where available; conversation history is kept only in page memory.
