# 角色日记与共同生活

## 使用入口

点击角色头像 →「日记与关系」。保留原来的只读资料页和日程月历，新增内容沿用中性灰白、绿色开关、系统字体。

阅读版可以独立启停。日记与见面共用同一个创作预设库（设置 → 提示词 → 创作预设）：同一套 JSON 导入、提示词分项编辑、开关、编排与模型参数。日记可沿用角色的见面预设，也可独立选择，或者不用预设。默认日记文风为第一人称、约 600–1200 字。原有文风文字保留为本角色的“日记补充要求”。可重写阅读版，但不能通过重写改变已经保存的记忆。用户阅读是旁观权限，不代表用户在故事内获知了这些内容。

共享预设的编辑会在下一次生成时生效，影响所有使用它的见面和日记；日记的独立选择不会改掉角色的见面绑定。删除单独选择的预设后回到默认文风，不会悄悄改用其他预设；已有正文和摘要保留。正在进行的生成使用调用开始时的预设快照。

日记复用见面兼容编排引擎的 Prompt 顺序、role、in-chat 位置和宏，但替换运行时上下文：char 为日记主人，user 为“读者”，时间为经历发生时间，chatHistory/scenario 只包含这一段已确认经历。charDescription 使用本人 SOUL 摘录；用户画像和私聊历史不进入插槽，未知动态插槽不加载其他数据。扩展脚本不执行。启用的预设参数仅用于阅读版，maxTokens 受 6000 的后台上限约束；摘要既不应用提示词预设，也不应用它的模型参数。

## 经历与两条生成路径

只有已结算的经历进入队列：自主日程完成、角色间交流完成、世界现场事件结束。升级不自动回填历史，也不会因为经过一天就凭空补写生活。

每个角色保存一份自己的来源快照：发生时间、世界、本人 SOUL 摘录、本人观察，以及确实参与的交流原文。共同交流的原文可以双方可见，但主观回顾只使用各自那份。世界事件不向角色复制全知结局，也不为没有观察记录的角色制造记忆。

- 阅读版：世界导演模型按预设创作，无工具权限。正文绝不作为摘要、关系或世界事实的输入。
- 记忆版：世界分析模型（未指定时回退导演/默认模型）独立读取来源，最多 6 个短记忆点，每点至多 120 字，分别标注经历、个人理解、未完事项。每点必须引用来源中的原文依据；推测不能提升为事实。

启用角色记忆能力且允许写入时，短摘要进入角色的持久记忆；最近四份有效摘要也作为当前世界中的本人上下文，供私聊、自主规划、角色间交流与世界叙事使用。它不是所有角色共享的记忆库。秘密空间不注入这些世界日记；无痕子实例不会新建或整理日记。既有无痕会话的历史继承规则保持不变。

撤销已结算的世界事件时，其日记保留给用户查看并标记已撤销，相关工作停止，持久记忆归档，不再注入角色上下文。重新结束该事件会产生新版本的经历记录。

## 关系演进

沿用好感、信任、紧张、亲密的方向性维度，另存显式恋爱状态：无恋爱关系、表达好感、交往、承诺、曾经交往。数值再高也不会自动升级关系。

第一版从**角色间实际交流的署名原文**提取里程碑：单方面表达好感或拒绝可以单向生效；确认交往、承诺、复合必须有双方分别表达的依据；任一方明确分手可以结束关系。解释由模型完成，应用验证角色归属、置信度、原文出处、方向、允许的状态迁移和幂等性，并保存前后状态与证据。延迟处理的旧经历不能覆盖更新的关系事件。

SOUL、取向、已有承诺和边界约束参与者与摘要模型；普通友善、靠近、性别和题材都不构成恋爱确认。模型分类仍可能出错，原文匹配只能验证出处，不能代替对语义的判断。

世界现场的自由叙事目前只生成观察与日记，不从难以可靠归属说话者的文学正文中自动判定恋爱里程碑。不会把写作预设或用户希望的配对直接变成关系事实。

## 后台与数据

SQLite schema 52 保存来源、两个独立任务、调用记录和关系证据，schema 53 增加共享预设绑定。升级保留已有文风文字与启停状态：填写过旧版自定义文风的角色默认不额外叠加共享预设；其余角色默认沿用见面预设。默认随世界后台每 60 秒扫描，一次扫描最多处理四个任务，串行调用；每次请求 90 秒超时。每个角色滚动 24 小时最多 3 次长文调用、12 次摘要调用，包含失败与手动重试，额度耗尽后顺延。每任务自动重试至多三次，失败间隔十分钟，可由本地界面重新排队。

生成前取得可恢复的租约；关闭创作、撤销经历、删除数据后，迟到输出不能落盘。摘要先保存已验证的检查点，再幂等写入记忆和关系；中途失败只重放同一份摘要，不重新解释已有落盘操作。

资料页展示最近 50 条；完整普通空间导出和状态备份包含所有日记及关系证据。秘密空间导出不包含这些数据。删除全部数据与角色/世界级联删除覆盖新增表。升级只增加新表与默认无恋爱状态，不改写既有关系分数；需要重启服务才会加载新版与迁移。

## 验证

`test/character-diaries.test.ts` 覆盖生成独立性、来源证据、角色归属、开关与失败、重试幂等、调用限额、事件撤销、日程与互动接入、关系证据、数据导出与清理、schema 51 升级和重启恢复。

`test/character-diaries.browser.mjs` 使用独立测试实例，验证 320/390/1440px 下的头像入口、阅读、设置、重写、记忆不变、角色切换和 HTML 安全；已纳入浏览器回归入口。

`test/diary-presets.test.ts` 覆盖继承与独立绑定、共享预设更新/删除、来源与用户画像隔离、编排和宏、实际 HTTP 模型请求参数、schema 52 升级、HTTP 输入校验及重启恢复。浏览器回归同时验证从日记进入同一个共享预设编辑器、保存、返回和重写生效。
