# 界面外观

在“设置 → 外观”选择跟随系统、浅色或深色。默认跟随设备，手动选择保存在当前浏览器；系统外观变化和同源标签页的设置变更会即时同步。偏好在首屏样式前读取，避免深色模式刷新时先闪出白底。浏览器禁用本地存储时仍可临时切换。

界面使用黑白中性色。用户消息为深底白字；头像原图保持不变，默认图标底色和按钮控件同步主题。深色使用分层灰色区分页面、卡片、聊天气泡与输入区，警告、错误、在线状态仍保留语义颜色。图片和二维码不做反色处理。

上下文余量为 18px 圆环，弧长表示已用比例。悬停可看数值，点击打开原有详情；不再常驻显示文字或百分比。

验证入口：`test/appearance.test.ts`、`test/context-budget-ring.test.ts`、`test/appearance.browser.mjs`。覆盖主题持久化、系统/标签页同步、存储不可用、手机和桌面布局、聊天 Markdown、日历、搜索与余量弹窗。
