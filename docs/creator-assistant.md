# 创作助手 · 第一期

入口是 **管理 → 创作助手**。它是世界之外的编辑，不是一个拥有隐藏管理员标记的普通角色。
使用当前默认模型；独立对话记录，不加入世界、角色私聊、角色自主社交、日记来源或记忆提取队列。

## 可以做什么

- 对话讨论角色与世界设计，分页查看角色身份和世界索引。
- 按 ID 查看世界规则、地点、成员，或角色名字、完整 SOUL、世界归属、自主生活配置与运行状态。
- 提出创建/修改世界、角色、地点的草案。
- 提出角色世界归属、居所、当前位置的调整草案。
- 提出自主生活、主动消息、角色社交开关，以及每日限额和安静时段的调整草案。
- 页面显示具体字段、修改前的值、完整原始快照；用户逐份确认应用或撤销。

示例：先要求“创建一个海边小镇世界”。确认创建后，再要求添加书店与角色；再次确认后，
助手通过概览读取真实 ID，提出加入世界和开启自主生活的草案。不猜测未发布对象的 ID，
不把“用户在聊天里说批准”视为页面确认，不自动串行发布全部草案。

## 明确不开放

本期没有删除/历史改写、读写关系记忆、私聊/私密/无痕内容、日历代编辑、
用户日程、模型或权限绑定修改、凭据读取、文件与 shell、网络抓取、MCP 安装/构建/部署。
原有日历及角色设置页不受影响。日程管理助手和 MCP 工坊是后续独立扩展，不能由一段角色设定自动授权。

不自动读取任何角色记忆。角色 SOUL 是编辑对象，可按明确目标读取；全局概览不读取所有 SOUL。
运行诊断只看到生活运行状态及后台忙碌信号，不读取私有任务内容或模型密钥，也不能据此声称已经定位所有运行故障。

## 执行与安全边界

- `CreatorService` 持有独立回合和草案状态。模型只取得 `creator_overview`、`creator_inspect`、
  `creator_propose` 三个 MCP 工具，没有 apply/review 工具。普通角色和委托子任务的工具目录不注册这个 MCP。
- 每回合使用独立 Pi 内存会话；禁用内建工具、自动上下文文件、Skills、插件和提示词模板加载。
  复用现有 MCP→Pi 适配器与模型配置，不复用角色会话历史或角色能力集合。
- 所有创作 HTTP 接口（包括读取快照）都是受本地控制平面凭据保护的 POST，校验 Host、Origin、
  JSON、请求上下文和 HttpOnly Cookie；不允许普通无凭据客户端通过这些接口读取或执行管理记录。
  这是现有单用户、可信本机部署的边界，不是多租户账号授权。拥有本机任意代码执行/网络控制能力的进程，
  本就不属于该边界内的不可信访客；不要将服务未经认证直接暴露公网。
- 草案严格使用白名单 schema，包含不可变操作、原始快照及 SHA-256 摘要。页面提交草案 ID 和摘要，
  后端只执行自己保存的操作，不接受审批请求中的替换操作。已有目标内容变化或被移除时草案失效。
- 使用现有 Kernel/domain 服务校验和写入。确认前检查普通对话能力执行与世界后台活动，忙碌时拒绝应用。
  自动生活本来就可能写入配置，因此待审草案可能过期；重新读取并提出草案即可，不强行覆盖。
- 每份草案独立确认、独立回执。重复确认已应用版本仅返回回执。没有批量事务或自动回滚承诺。
  应用前持久记录 applying；服务中断后变为 interrupted，结果可能已生效，必须检查后重新提出草案，绝不自动重试。
  失败变更也不会自动重试，因为现有部分领域操作同时涉及数据库和文件系统。
- 重复消息请求 ID 不再启动模型；同一工具调用 ID 不重复创建草案。运行中不能应用草案。
  停止/超时/失败会撤销本轮未应用草案；重启后未完成回合的草案也被撤销。
  运行创作回合期间不能进入无痕或清空用户数据。

## 预算与数据保留

每轮最多 8 次模型请求、16 次管理工具调用、120 秒；最多 20 份待确认草案。
每次输出最多 8192 tokens（也受模型配置及窗口限制）；请求重试关闭，单次网络空闲超时 60 秒。
单条输入上限 8000 字符，持久回复上限 20000 字符。送给模型的历史按长度预算截取最近记录，
工具上下文也有长度上限；上下文过长时本轮结束，不开启额外自动摘要模型调用。
页面每次取 30 条消息，可加载更早记录；草案列表优先显示待确认项，再显示近期记录，共最多 40 份。

数据库迁移 55 新增 `creator_turns`、`creator_messages`、`creator_proposals`。
不绑定 role session，不进入普通记忆，但管理对话及设定草案本身仍属于持久化的用户数据。
普通空间完整导出包含全部创作记录，私密导出不包含；清空全部用户数据会一起清除这些表。
常规备份包含创作记录，备份/恢复支持的数据库版本同步升至 55。
删除某个角色不会自动抹去用户在管理会话中讨论过它的文本或审核快照；不再存在的对象不能用旧草案恢复或覆盖。

## 测试

`test/creator.test.ts` 覆盖 MCP/Pi 白名单、审批版本、重放幂等、冲突、域操作、权限边界、
角色会话隔离、取消、历史分页、迁移/重启、清空/导出及本地 HTTP 防护。
`test/creator.browser.mjs` 覆盖桌面浅色和手机深色，聊天提出草案、内容转义、展开预览、
二次确认、应用回执、刷新不重放、刷新页面恢复记录及窄屏布局，并接入完整浏览器回归。
