# 角色近况、持续事项与离场

第一轮实现保留头像与聊天入口，不增加独立的任务看板。点击角色头像 → **近况**，可查看持续事项、后台活动和曾经一起生活的人。原有日程月历继续使用。普通与私密空间分别读取，切换角色或空间后丢弃迟到的页面响应；无痕界面不维护持续事项。

## 持续事项

- **用户委托**：在近况中明确创建，只进入该角色、该空间的私聊上下文。换会话或重启仍可接着讨论。第一轮不会主动启动无人值守的现实工作，不从普通聊天自动推断授权，也不向世界规划或其他角色传递委托。
- **世界心愿**：普通空间的世界成员可以创建。开启已有的自主生活开关后，后续日程规划可围绕心愿提出小活动；休息与无目标的日常活动仍然允许。心愿不授权现实操作，不保证其他角色的回应或恋爱结果。

每个角色、每个空间、每类最多一个未结束事项，暂停也占用名额。支持记录下一步/等待条件、调整、暂停、继续、取消、用户确认完成。修改校验 revision，防止旧页面覆盖新设置。

规划只接受调用开始时提供、且返回时仍有效的心愿 ID；期间暂停、取消、修改下一步、换世界或关闭自主生活，相关迟到计划不会被采用。心愿日程仍存储在原有日程和活动计划中，通过关联步骤记录出处。

只有关联活动已经结算、且存在对应的 canonical world event 时，步骤才显示“已发生”。重启后的确定性核对可以补齐进展，重复核对不重复记忆或日程。完成一个步骤不会自动宣布整个心愿实现；“确认完成”需要填写用户验收依据，并明确标记为用户确认，不冒充工具执行证明。文学日记绝不作为事项完成依据。

暂停、取消、完成事项会取消它尚未开始的关联日程；已经开始或发生的经历不撤销。继续事项不会重新激活已取消日程。当前不提供多目标自动协调、现实工作后台续跑、角色自动创建心愿或全量可视化工作流。

## 统一后台活动入口

`CharacterBackgroundTasks` 对已有日记任务、角色协作任务和世界规划提供统一的归属、状态、来源、错误和操作能力投影，不另建一套竞争的日记/协作队列。

- 日记：可停止单次摘要或长文任务；取消标记不会被定时扫描或设置开关悄悄清除。用户显式重排仍受现有调用额度限制，已验证摘要检查点复用。
- 角色协作：发起角色可停止排队/执行中的持久协作。取消首先撤销数据库执行租约，再中断模型请求，迟到结果和汇报不能重新落盘；已发消息保留。接收角色的近况只能查看该任务。第一轮不提供通用协作重试按钮。
- 世界规划：新增持久执行记录、单角色并发防重、90 秒中断信号与滚动 24 小时最多 3 次规划尝试（包括手动强制规划）。用户对话正在执行时不启动规划。每日尝试检查点在调用前保存，取消后下一次定时扫描不会立即重开同一日规划。重启将未完成规划标记中断，不恢复未确认输出；之后按原日程策略处理，用户也可在原生活设置中明确再次规划。

现有各模块的预算与恢复策略保持独立。此次没有统一所有后台服务的调度器，也没有移除角色删除时其他子系统的保守忙碌检查。取消不是回滚，不保证第三方服务已经发生的动作能撤销。

## 删除与离场

角色编辑页的移除方式明确区分：

1. **搬家离开 · 保留他人的回忆**（默认）：移除活动角色及其专属数据，并给有真实交集的角色保存最小历史身份、本人方向的关系快照、已知共同经历和一条离场消息。该消息是用户确认的世界状态变更，不是虚构的告别对话。默认只说搬离、暂时无法联系，去向和原因未知。
2. **仅删除角色数据 · 不新增离场回忆**：沿用角色专属数据清理，不新建历史身份或搬家记忆。其他角色已有记忆、共享历史、工作区文件、备份和记忆版本历史仍保留；此选项不是全文抹除或法证级清除。完整数据删除仍走独立的清除流程。

真实交集来自已完成角色交流、共同 world event、本人日记来源中的署名交流、带明确角色/世界标签的已确认普通记忆，或已有关系记录。不会按姓名模糊匹配，不会因为住在同一世界就让陌生人凭空认识对方。不会复制离开者的 SOUL、用户私聊、秘密空间记忆或文学日记作为事实。

离场记录归仍存在的观察者所有，引用不可复用的历史角色 ID，而非依赖即将删除的角色外键。删除角色与写入离场记录处于同一 SQLite 事务。与离开者相关的未结束世界事件取消，既有结算历史与其他角色的日记不改写。离开时的朋友/恋爱关系作为历史保留，搬家不会自动分手或清零。重建同名角色不会自动继承旧身份和关系。

离场后不再出现在当前地图、可邀约目录或后台活动中；相关人的“近况”和“日记与关系”仍可看到其历史身份。普通世界上下文可以读取该观察者的离场事实，秘密与无痕上下文不注入。

用户明确确认的离场消息也幂等写入相关角色的普通 Memory Vault，成为可检索的简短关系记忆，不依赖文学生成或模型推断。事务中保留待投影标记；若文件写入中断，重启或读取近况时重放同一条事实，不能重复写入或将已成功删除误报为失败。此行为来自本地用户的移除操作，不是授予角色自动记忆写入权限。

## 数据与验证

SQLite schema **54** 新增持续事项、关联步骤、规划任务及离场记忆表，并为日记任务增加持久取消标记。备份工具的版本上限同步升级。完整数据导出按空间包含全部持续事项；普通导出额外包含完整离场历史；删除全部数据以及角色/世界级联清理覆盖新表。

近况默认读取最多 30 件事项、每件最近 20 个步骤、60 条后台活动和 20 位离开者（每位最多 8 段有限长度的共同经历）。模型只读取精简的事项与离场上下文，不把全部历史装入提示词。完整历史仍在导出与备份中；详细分页回溯界面留到后续阶段。

`test/character-life.test.ts` 验证所有权与空间、名额与 revision、日程闭环、防重复进展、取消与迟到结果、模型上下文、离场隐私、关系保留、同名新角色、重启、迁移和 HTTP 控制面保护。`test/character-life.browser.mjs` 覆盖窄屏、浅/深色、近况操作、离场展示、空间切换及 HTML 转义，并纳入主浏览器回归。
