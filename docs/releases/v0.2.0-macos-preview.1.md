# YourChar v0.2.0 macOS Preview

Apple Silicon · macOS 13+ · ad-hoc signed · **not Apple-notarized**

## 本次更新

- **原生沙箱**：macOS Shell 使用 Seatbelt，不要求另装容器服务；Shell 仍需在 Agent 管理中主动启用。角色的 Workspace 文件权限默认可读写，已有的关闭/只读设置会保留。
- **开箱即用的文档解析**：安装包内置 Node.js、Python 3.13.5 和锁定依赖的 MarkItDown，无需用户维护 Python 环境。文档转换使用独立断网沙箱。
- **代码导航与无痕模式**：TypeScript LSP 使用只读 Workspace 和断网沙箱；工作进程临时空间与无痕状态使用可验证的私有 RAM 盘，包含退出清理和崩溃残留恢复。隔离不可用时停止操作，不降级为普通磁盘临时目录。
- **界面与日常使用**：包含中英文界面、模型设置页对齐修正、文件入口前移，以及用量统计与费用估算。
- **跨平台准备**：Linux 保留 Bubblewrap 路线；新增 Windows WSL2 启动脚本与验收清单，Windows 实机验证仍待完成。本 Release 只提供 macOS 安装包。

## 下载与升级

选择 `YourChar-0.2.0-macos-arm64.dmg`（推荐）或同名 ZIP；`SHA256SUMS.txt` 提供两种格式的校验值。

升级前用 **⌘Q** 完全退出 YourChar，备份 `~/Library/Application Support/YourChar`，再将新版拖入 Applications 并选择替换。不要删除数据目录，已有聊天与配置会保留。退出安装磁盘镜像后，从 Applications 启动新版。没有自动更新器；完整步骤见[安装与升级说明](https://github.com/Tylogi/YourChar/blob/v0.2.0-macos-preview.1/docs/macos-release.md#install-or-upgrade)。

本预览版尚未经过 Apple 公证，首次打开仍可能出现系统安全提示；仅在信任来源并核对下载后，按照 [Apple 官方说明](https://support.apple.com/en-us/102445) 对该应用单独放行，不要全局关闭 Gatekeeper。

## 验证范围与已知限制

- Linux 回归测试；Apple Silicon / macOS 26.6.2 原生沙箱、文档转换、LSP 和无痕生命周期测试。
- 签名后再验证实际打包的文档转换和跨文件代码导航，并使用独立测试数据执行启动检查。
- macOS 13 是打包目标的最低要求，尚未覆盖每个旧版 macOS 的实机测试；不提供 Intel Mac 安装包。
- 无痕模式不控制模型服务商的数据保留，也不承诺操作系统不会使用 swap。
- 安装包因内置 Python 和文档解析依赖而比上一版更大。

## English summary

This preview adds native macOS Seatbelt workers, bundled Python/MarkItDown,
offline document conversion and TypeScript navigation, and verified RAM-backed
incognito/worker storage with crash recovery. It also includes Chinese/English
UI settings, model-settings layout fixes, prominent file navigation, and usage
tracking with cost estimates. Shell remains opt-in; Workspace file access
defaults to read/write while preserving existing choices.

Quit YourChar before replacing the app in Applications and back up its
Application Support directory; do not remove that directory to upgrade.
The app needs no separately installed Node.js or Python. This is an
**Apple Silicon-only, macOS 13+ preview**, tested on macOS 26.6.2, with ad-hoc
signing but **no Apple notarization**. Windows/WSL2 real-machine acceptance is
still pending, and no Windows installer is included.
