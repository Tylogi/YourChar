# YourChar v0.2.1

This patch release adds ChatGPT account sign-in for the Codex model provider and
separates schedule notifications from character replies. It also includes chat
interruption, failed-message recovery, configurable upload limits, and corrected
image context estimates.

## macOS

The Apple Silicon app uses Developer ID signing and Apple notarization. Both the
app and DMG carry stapled tickets. Embedded Node, Python, and native libraries
are signed before the outer application bundle. Node.js and Python do not need
to be installed separately. Requires macOS 13 or later; native validation runs
on the release Mac and does not establish physical-machine coverage of every
supported macOS version.

The client includes the standard Edit menu for copy, paste, cut, select-all,
undo, and redo. Native regression checks cover keyboard shortcuts and WebKit's
right-click copy/paste menu with Chinese text and emoji.

Quit YourChar and back up `~/Library/Application Support/YourChar` before
replacing the app in Applications. Keep that data directory to retain settings,
characters, and conversations. The Windows installer remains on its previous
preview release.

## Conversations and models

- Codex supports browser and device-code ChatGPT login, host-owned credentials,
  automatic token refresh, logout, and account-specific model access. Live login
  and access depend on the account; using the provider consumes its Codex quota.
- Schedule reminders appear as compact cards with acknowledgement and snooze
  controls. Ordinary chat instructions keep calendars in the background and
  avoid repeated reminders. Notification timing and channel settings still apply.
- New messages can interrupt an active private-thread response. Failed inputs
  remain visible and can be restored to the composer, while completed tool side
  effects remain protected from unsafe replay.
- Upload limits are configurable, with a default of 100 MiB. Multimodal context
  estimates account for image inputs without treating Base64 transport bytes
  as ordinary text tokens.

Use `SHA256SUMS.txt` to verify downloaded artifacts. The release publishes the
source commit alongside its installer assets; credentials are never bundled.
