# YourChar v0.2.1

稳定版 · 新增 ChatGPT 账号登录，改进创作助手、日程提醒和 macOS 编辑操作。

## 本次更新

- **ChatGPT 账号登录**：Codex 模型提供方支持浏览器登录和设备码登录，使用账号可用的模型与额度。
- **创作助手**：支持独立会话和可编辑草稿；切换会话保留草稿，发送失败后可以重试。
- **日程提醒**：提醒以独立卡片展示，支持确认和稍后提醒，减少普通对话中的重复提醒。
- **聊天恢复**：新消息可以打断正在进行的私聊回复，失败输入可以恢复到输入框。
- **macOS 编辑菜单**：补齐复制、粘贴、剪切、全选、撤销和重做，并验证中文与 emoji 操作。

使用 ZIP 时，先解压再将应用放入 Applications。无需另外安装 Node.js 或 Python。

文件校验：[SHA256SUMS.txt](https://github.com/Tylogi/YourChar/releases/download/v0.2.1/SHA256SUMS.txt)。

## 升级与注意事项

- 升级前用 **⌘Q** 完全退出 YourChar，并退出单独运行的旧后端；备份
  `~/Library/Application Support/YourChar` 后替换应用，保留该数据目录。
- 首次启动会迁移创作助手历史并升级数据库。回退旧版时应使用升级前的数据备份。
- 本版采用手动升级，仅提供 Apple Silicon 安装包；尚未逐一验证所有支持的 macOS 版本。
  Windows 用户继续使用独立的 [Windows 预览版](https://github.com/Tylogi/YourChar/releases/tag/v0.2.0-windows-preview.1)。

## English summary

This release adds ChatGPT account login for the Codex provider and improves
creator drafts, schedule reminders, chat recovery, and macOS editing commands.
The Apple Silicon app requires macOS 13 or later and is Developer ID signed
and Apple-notarized. Quit YourChar and back up its data before replacing the
app, as the first launch migrates creator history and upgrades the database.
The Windows installer remains on its separate preview release.
