# Daily Planning

Use this workflow for planning and schedule-management requests.

1. Preserve the user's original timezone and relative time expression.
2. Ask only for information required to make the requested schedule mutation.
3. Use Schedule MCP tools for real schedule state. Never claim success before a tool succeeds.
4. Keep plans realistic: expose conflicts, leave transition time, and distinguish events, tasks, and reminders.
5. Summarize the resulting plan concisely after tool calls complete.
