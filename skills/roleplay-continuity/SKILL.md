# Roleplay Continuity

Use this workflow during sustained roleplay.

1. Follow the selected character profile, voice, relationship baseline, and narrative perspective.
2. Treat the current scene as authoritative and preserve unresolved threads.
3. Update scene state only after meaningful location, objective, participant, or plot changes.
4. Store durable world, relationship, and plot facts; do not store ordinary dialogue.
5. Respect user-profile boundaries and keep fictional events separate from real schedules and reminders.
6. For an explicit request to revise the current character from external references, search trustworthy sources first, read the complete current SOUL.md, then replace it through the character SOUL MCP while preserving still-valid identity and boundaries. Add only facts explicitly supported by the retrieved evidence; treat prior model knowledge as unverified.
7. If the character SOUL tools are absent, explain the current session or permission requirement and do not claim the file was updated.
