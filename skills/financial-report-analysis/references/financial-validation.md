# 财务事实账本与校验规则

完整财报分析在形成结论前使用本规则。原始报告是事实来源，参考答案只能用于事后比较。校验应围绕会改变结论的核心数字进行，不要求穷尽全部附注。

## 事实账本

每个数字至少记录以下字段：

```text
fact_id:
metric:
statement: summary | income_statement | balance_sheet | cash_flow | note | management_discussion
scope: consolidated | parent | segment | subsidiary
period: YYYYH1 | YYYYQ1 | YYYYFY | YYYY-MM-DD
period_kind: flow | point_in_time
unit: CNY | CNY_10K | percent | percentage_point | other
value:
comparison_period:
comparison_value:
source_page_or_lines:
source_label:
confidence: high | medium | unresolved
```

只有 `confidence=high` 的核心数字可以直接支撑核心结论。若来源表格出现列错位，应找到另一处同口径披露或通过完整勾稽确认；二者满足其一即可，不要为同一数字无限搜索。

## 口径检查

逐项确认：

- 合并报表与母公司报表没有混用。
- 利润表和现金流量表使用本报告期与上年同期；资产负债表使用期末与期初。
- 元、万元、亿元和百分比没有混用。
- 空白、短横线、零和负号按表头列位置确认，不能仅凭相邻文本猜测。
- 同一个金额出现在不同科目时重新核对行名，防止把固定资产、应收账款等串行。
- 管理层口径、非公认会计指标和法定报表指标分别命名。

## 必做勾稽

按任务涉及范围执行；计算结果保留足够精度，展示时再统一舍入。

### 利润

```text
毛利 = 营业收入 - 营业成本
毛利率 = 毛利 / 营业收入
扣非归母净利润 ≈ 归母净利润 - 归属于母公司股东的非经常性损益
```

“扣除股份支付影响后的净利润”不是“扣非归母净利润”，两者必须分别记录。

### 现金流

```text
经营活动净额 + 投资活动净额 + 筹资活动净额 + 汇率变动影响
  = 现金及现金等价物净增加额
期初现金及现金等价物 + 净增加额 = 期末现金及现金等价物
```

某项本期为空而比较期有数值时，先根据表头和合计判断本期是否为零，禁止把比较期数值移到本期。

### 资产负债与营运资本

```text
资产总计 = 负债合计 + 所有者权益合计
流动比率 = 流动资产合计 / 流动负债合计
速动口径必须明确，不得直接把“货币资金 + 理财”称作全部流动资产
科目变动率 = (期末 - 期初) / abs(期初)
```

若声称某科目“快于收入增长”，必须实际比较两者百分比；下降的科目不能被描述为上升或占用增加。

## 核心事实最低清单

完整分析优先核实：

- 营业收入、营业成本、毛利率、归母净利润、扣非归母净利润。
- 与利润变化有关的销售、管理、研发、财务费用及重要非经常性损益。
- 经营、投资、筹资现金流，汇率影响、现金净变化和期末现金。
- 货币资金、应收账款、存货、流动资产、流动负债、总资产、总负债、净资产。
- 固定资产、在建工程、购建长期资产支付现金等资本开支指标。
- 至少一组能够解释当期变化的主要产品或项目事实。客户、供应商和研发明细仅在它们支撑重要结论时继续读取。

## 最终反查

交付前扫描正文中的每个金额和百分比：

1. 能否映射到一个高置信度事实或明确公式？
2. 页码、期间、单位、正负号和合并口径是否一致？
3. 同一指标在全文是否使用同一个数值？
4. 推断是否真的由引用事实推出，还是只与叙事方向相符？
5. 若删除某个错误数字，对应风险或结论是否随之失效？若是，必须重写该结论。
